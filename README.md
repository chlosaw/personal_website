# Nataliia Burba — Personal Website

This is the source code of my personal website, where I present my AI content creation services and the AI tools I've built.

🌐 **Live at [nataliiaburba.space](https://nataliiaburba.space)**


## What's on the site

- **Services**: AI video creation, AI brand sets and AI content packs for businesses
- **Projects**: AI tools I've built, including [Triago](https://triago.bid/) (support emails into structured tickets), PDF Analyzer and Questbe
- **About & experience**: 7+ years in tech, including work with Clario Tech, MUFG Bank and Volkswagen GIS
- **Contact**: a form to send me a message directly

## Built with

- Plain HTML, CSS and JavaScript in a single page, with no build step
- An animated synthwave terrain background drawn on a canvas
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- [Web3Forms](https://web3forms.com/) for the contact form
